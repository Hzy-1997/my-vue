# 文件下载功能实现指南

## 一、现有 request.js 的限制 今天没有更新吧？

当前的 `request.js` 只能处理普通的 JSON 请求，无法下载文件，原因如下：

1. **响应类型限制**：axios 默认的 `responseType` 是 `'json'`，无法处理二进制文件数据
2. **数据处理方式**：现有的响应拦截器期望返回 JSON 格式的数据，不适合文件流
3. **缺少 Blob 处理**：文件下载需要将响应数据转换为 Blob 对象

## 二、后端接口说明

后端已提供订单导出接口 `exportOrder`（位于 `seckillPayment.js`），支持以下功能：

```javascript
// POST 请求示例
{
    outTradeNo: "订单号",    // 可选
    userPhone: "手机号",     // 可选（加密后）
    userIdCard: "身份证",    // 可选（加密后）
    startDate: "开始日期",   // 可选
    endDate: "结束日期",     // 可选
    orderStatus: 1,         // 可选，订单状态
    ticketType: "票务类型"   // 可选
}
```

后端返回 Excel 文件流，响应头设置：

```javascript
res.setHeader(
  "Content-Type",
  "application/vnd.openxmlformats-officedocument.spreadsheetml.sheet",
);
res.setHeader(
  "Content-Disposition",
  "attachment; filename=" + encodeURIComponent("门票订单详情.xlsx"),
);
```

## 三、解决方案：已封装到 request.js

下载功能已直接封装到 `src/utils/request.js` 中，提供统一的文件下载方法，**自动兼容 GET 和 POST 请求**。

### 3.1 安装依赖

需要安装 `file-saver` 库来支持文件保存：

```bash
npm install file-saver --save
```

### 3.2 统一下载方法特点

`downloadFile` 方法会自动判断使用 GET 还是 POST 请求：

- **有 `data` 属性** → 自动使用 POST 请求
- **有 `params` 属性** → 自动使用 GET 请求
- **明确指定 `method`** → 使用指定的请求方法

### 3.3 使用方法

首先导入下载方法：

```javascript
import request, {
  downloadFile,
  downloadGet,
  downloadPost,
} from "@/utils/request";
```

#### 方式1：字符串URL（默认GET请求）

```javascript
// 最简单的用法
downloadFile("/api/export", "文件.xlsx");
```

#### 方式2：GET请求（参数通过params传递）

```javascript
downloadFile(
  {
    url: "/api/export",
    method: "get",
    params: { id: 123, type: "report" },
  },
  "文件.xlsx",
);
```

#### 方式3：POST请求（参数通过data传递）

```javascript
downloadFile(
  {
    url: "/api/payment/exportOrder",
    method: "post",
    data: {
      startDate: "2024-01-01",
      endDate: "2024-12-31",
      orderStatus: 1,
    },
  },
  "订单.xlsx",
);
```

#### 方式4：自动判断（推荐）

```javascript
// 有data自动使用POST
downloadFile(
  {
    url: "/api/payment/exportOrder",
    data: {
      startDate: "2024-01-01",
      endDate: "2024-12-31",
    },
  },
  "订单.xlsx",
);

// 有params自动使用GET
downloadFile(
  {
    url: "/api/export",
    params: { id: 123 },
  },
  "文件.xlsx",
);
```

#### 方式5：快捷方法

```javascript
// GET请求快捷方法
downloadGet("/api/export", { id: 123 }, "文件.xlsx");

// POST请求快捷方法
downloadPost(
  "/api/payment/exportOrder",
  {
    startDate: "2024-01-01",
    endDate: "2024-12-31",
  },
  "订单.xlsx",
);
```

```vue
<template>
  <div class="export-container">
    <el-form :model="searchForm" inline class="search-form">
      <el-form-item label="订单号">
        <el-input v-model="searchForm.outTradeNo" placeholder="请输入订单号" />
      </el-form-item>

      </el-form-item>
      <el-form-item label="订单状态">
        <el-select v-model="searchForm.orderStatus" placeholder="请选择状态">
          <el-option :label="'待支付'" :value="1" />
          <el-option :label="'待核销'" :value="2" />
          <el-option :label="'已取消'" :value="3" />
          <el-option :label="'已完成'" :value="4" />
          <el-option :label="'已退款'" :value="5" />
        </el-select>
      </el-form-item>

        <el-date-picker
          v-model="searchForm.dateRange"

<script setup>
import { ref, reactive } from "vue";
import { ElMessage } from "element-plus";
import { Download } from "@element-plus/icons-vue";
import { downloadPost } from "@/utils/request";

const exportLoading = ref(false);
const searchForm = reactive({
  outTradeNo: "",
  userPhone: "",
  userIdCard: "",
  orderStatus: "",
  dateRange: [],
});

const handleExport = async () => {
  exportLoading.value = true;

  try {
    // 构建请求参数
    const params = {
      outTradeNo: searchForm.outTradeNo,
      userPhone: searchForm.userPhone,
      userIdCard: searchForm.userIdCard,
      orderStatus: searchForm.orderStatus,
    };

    // 处理日期范围
    if (searchForm.dateRange && searchForm.dateRange.length === 2) {
      params.startDate = searchForm.dateRange[0];
      params.endDate = searchForm.dateRange[1];

      "/api/payment/exportOrder",
      params,
      `订单导出_${new Date().toLocaleDateString("zh-CN").replace(/\//g, "-")}.xlsx`,

    ElMessage.success("订单导出成功");
  } catch (error) {
    ElMessage.error("订单导出失败，请重试");
    console.error("导出错误:", error);
  } finally {
    exportLoading.value = false;
  }
};
</script>
```

## 五、方法对比

| 方法             | 说明                       | 适用场景           |
| ---------------- | -------------------------- | ------------------ |
| `downloadFile()` | 统一方法，自动判断GET/POST | 通用场景，推荐使用 |
| `downloadGet()`  | GET请求快捷方法            | 参数较少，简单查询 |
| `downloadPost()` | POST请求快捷方法           | 参数较多，复杂查询 |

## 六、注意事项

### 6.1 Token 认证

后端接口需要认证，`request.js` 的请求拦截器会自动携带 Token：

```javascript
server.interceptors.request.use((req) => {
  let storage = useStorage();
  let token = storage.comToken || "";
  const headers = req.headers;
  if (!headers.Authorization) {
    headers.Authorization = "Bearer " + token;
  }
  return req;
});
```

### 6.2 文件类型支持

下载方法会自动从响应头获取文件类型，也支持手动指定：

```javascript
// 自动检测（推荐）
downloadFile("/api/export", "文件.xlsx");

// 手动指定Blob类型
downloadFile(
  {
    url: "/api/export",
    responseType: "blob",
  },
  "文件.xlsx",
);
```

常见文件类型：

| 文件类型      | MIME 类型                                                                 |
| ------------- | ------------------------------------------------------------------------- |
| Excel (.xlsx) | `application/vnd.openxmlformats-officedocument.spreadsheetml.sheet`       |
| Excel (.xls)  | `application/vnd.ms-excel`                                                |
| PDF           | `application/pdf`                                                         |
| Word (.docx)  | `application/vnd.openxmlformats-officedocument.wordprocessingml.document` |
| ZIP           | `application/zip`                                                         |

### 6.3 文件名处理

1. **优先使用传入的文件名**
2. **其次从响应头获取**（后端通过 `Content-Disposition` 设置）
3. **最后使用默认名称** `downloaded-file`

### 6.4 大文件下载

如果下载大文件，需要增加超时时间：

```javascript
downloadFile(
  {
    url: "/api/export",
    data: { id: 123 },
    timeout: 60000, // 60秒超时
  },
  "文件.xlsx",
);
```

### 6.5 错误处理

下载失败时，方法会自动：

- 显示加载动画
- 解析错误信息
- 提示用户错误原因

## 七、推荐使用方式

**推荐使用 `downloadFile` 统一方法**，原因：

1. **自动兼容**：自动判断使用 GET 还是 POST
2. **代码简洁**：无需关心请求方法细节
3. **灵活性强**：支持多种使用方式
4. **易于维护**：一个方法处理所有下载场景
5. **集中管理**：与请求功能统一在一个文件中

**对于你的订单导出功能**，使用 `downloadPost` 或 `downloadFile` 都可以：

```javascript
// 方式1：使用downloadPost（明确POST）
import { downloadPost } from "@/utils/request";
downloadPost("/api/payment/exportOrder", params, "订单.xlsx");

// 方式2：使用downloadFile（自动判断）
import { downloadFile } from "@/utils/request";
downloadFile(
  {
    url: "/api/payment/exportOrder",
    data: params,
  },
  "订单.xlsx",
);
```

## 八、API 文档

### downloadFile(options, fileName)

通用文件下载方法。

**参数：**

- `options` (Object|string) - 请求配置对象或URL字符串
  - `url` (string) - 请求地址
  - `method` (string) - 请求方法（可选，默认自动判断）
  - `params` (Object) - GET请求参数
  - `data` (Object) - POST请求数据
  - `timeout` (number) - 超时时间（毫秒）
- `fileName` (string) - 下载文件名（可选）

**返回：**

- `Promise` - Promise对象

### downloadGet(url, params, fileName)

GET请求下载快捷方法。

**参数：**

- `url` (string) - 请求地址
- `params` (Object) - 查询参数
- `fileName` (string) - 文件名（可选）

### downloadPost(url, data, fileName)

POST请求下载快捷方法。

**参数：**

- `url` (string) - 请求地址
- `data` (Object) - 请求数据
- `fileName` (string) - 文件名（可选）

## 九、代码位置

所有下载方法均位于 `src/utils/request.js` 文件中，无需额外创建新文件。
